# 正常启动直接恢复已保存记录

正常打开 Blackjack 窗口时，直接恢复当前资料目录内最近一个已有录牌记录的会话，不再弹出“恢复会话／是否启用旧记录”的询问。只有启动事件的空会话不会挤掉已有录牌记录；没有录牌记录时才建立空会话。

恢复沿用既有完整读取和校验，保留原事件身份、顺序、牌靴规则及录牌位置。读取失败会停止启动并报告错误，不静默建立新会话。待核对输入、保存结果未知和结果保存失败仍使用原有核对及退出流程，不自动重试牌面。

资料范围仍由启动入口绑定：独立试用版只恢复自己的资料目录，不自动读取日常版数据库。需要新牌靴时，使用现有“新建牌靴”；已有历史保持保留。

本改动不改变主注分析、点值范围、边注停用状态或实时性能预算。源码回归检查与最终安装产物的正常启动验收分别记录；此前固定安装包和验收记录仍按各自原身份保留。
