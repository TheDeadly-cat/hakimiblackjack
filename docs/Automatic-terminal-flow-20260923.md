# 庄家自动停牌与玩家爆牌切换

新牌靴表单默认选择S17，即庄家17点停牌，包含A+6软17。其他桌规仍需确认，当前已锁定牌靴继续按其保存的规则处理：H17软17仍需补牌，未知软17规则不会被自动猜成S17。

庄家牌面完整后，达到适用停牌点会明确显示“已自动停牌”。小面板和工作台的牌面按钮禁用，继续按数字或点击录入不会额外记一张牌；庄家爆牌同样结束录牌。底牌未揭示时不根据可见牌猜终点。仍由用户确认本轮记录完整后结算，不自动代填观察事实、结算或新开轮。

玩家总点数大于21时，原有规则自动将该手闭合并推进录入位置。本次补齐“已爆牌”标识和明确的自动转入提示：普通手转到下一位未完成玩家，最后一位转庄家；分牌先转同一玩家的下一手，再到下一位玩家。A仍按1或11的有效点数计算，普通手恰好21点不会标成爆牌。

自动状态从账本重放的手牌和已锁定规则推导，不增加虚构的玩家动作事件。改牌、撤销和恢复都重新判断：例如庄家17改为16，牌面输入会重新启用；玩家撤销爆牌的最后一张后回到应录的手牌。录入目标与分析对象保持独立，逐玩家概率条件不变。

专项测试覆盖三人逐个爆牌、分牌第一手爆牌后续到第二手、A降点和21点边界、硬17/软17/H17/未知规则、额外数字输入无事件、改牌与撤销重新启用、重启恢复和下一轮重置。原有本轮人数调整、底牌重复按键、快照失效和日常流程继续回归；测试结论以本提交实际日志为准。
