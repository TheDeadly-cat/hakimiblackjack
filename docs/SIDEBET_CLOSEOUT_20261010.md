## 当前数值统一暂停

成功接收新牌后，主注、下轮EV、Perfect Pairs、21+3、已打开或随后打开的边注详情、保险和庄家BJ标签使用同一录牌状态。待保存、保存失败、提交结果未知，以及读回后发牌位置尚未核对时，都隐藏当前概率和EV，并明确显示“此前记录保留，当前暂停使用”。已保存牌面仍可查看。

恢复必须经过一致保存结果和当前录牌位置核对。提交成功但回传出错的测试实际写入SQLite，再注入异常；界面读回数据库后也不会越过尚待核对的发牌计划，立即恢复旧预测。原时点历史、未保存分析结果、失败输入和核对材料不清空，不自动重试未知提交。

当前暂停还区分计划失效的读回与已验证纠错：读回时未能绑定当前事件前缀的替代计划继续暂停，重启仍保持；已验证纠错后即使下一录牌位置需要手动选择，当前已记录牌型仍可按新前缀更新。不能把所有需要人工选择位置的状态一律当成提交结果未知。

## BCLC 三态设置

A23、QKA、KA2 使用“待确认 / 是 / 否”，分别保存为 `None / True / False`。默认BCLC未知档案可以直接打开设置；未知不转换为假，也不默认勾选。未确认细则不能保存为已经核对的完整档案。

配置跟随当前锁定牌靴；只有下一模式被选择而尚无牌靴时，设置对应所选模式。当前Pragmatic和BCLC文件独立，已打开的编辑器在实际换靴后载入对应档案。旧封盘历史保留原规则和赔付。
