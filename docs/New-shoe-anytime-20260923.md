# 随时新建牌靴

修复基线 `c298347`：自动结算会立刻打开下一轮，而原来的新建牌靴入口禁止在进行中的轮次使用，因此用户会被困在当前牌盒。

主界面顶部新增常驻 **新建牌靴**。首次创建直接执行；已经有开放牌靴时显示一次说明，确认后可在发牌中、玩家行动、庄家暗牌未揭示、录入暂停或刚自动开轮时换靴。新靴使用当前设置，不需要先补齐旧轮牌面。

进行中的旧轮追加 `ROUND_ENDED(settle=False, observation_status=unknown)`，随后 `SHOE_ENDED` 和 `SHOE_CREATED` 在同一数据库事务内保存。旧牌面、未知牌、观察缺口和历史结算保留；本次中断不输出输赢，不声明观察完整。新靴得到独立身份、完整的所选副数及新的锁定规则，旧缺口不带入新靴。未开轮或已结束的旧靴不重复结束轮次。

确认取消、规则校验失败、过期确认或任何一次数据库插入失败均不留下半次换靴。记录变化后，旧手牌和开局计算立即失效。

**Backspace 一次撤回整次换靴**，恢复旧轮牌面、发牌位置与暂停状态；已经在新靴录牌时先按既有规则逆序撤回后续记录。重启后仍可撤回。旧发牌位置未经验证时恢复为暂停核对，不猜测下一张归属。

本机10项新回归涵盖首次创建、暗牌/初始发牌/暂停/自动新轮、取消、过期确认、事务中途写入失败、无效新规则、组合撤回、恢复及旧计划异常；另跑自动下一局、默认设置和布局等相关回归。最终提交的 Windows CI、固定副本和原生窗口结果在 PR #23 中补充，旧固定运行副本保持原样。
