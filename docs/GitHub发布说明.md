# V0.1.1 GitHub 源码同步

2026-09-10，按用户要求将桌面项目 V0.1.1 同步到 `TheDeadly-cat/hakimiblackjack`。目标仓库在同步前为空，本次初始化主分支。

发布文件包括源码、中文运行说明、测试、验收脚本和已有本地验收证据。排除真实数据库、数据库备份、完整目录备份、缓存、打包压缩文件和环境密钥文件。桌面原项目保持不变。

`docs/review-20260910` 中的命令、路径、失败过程、最终回执和源文件清单均是此前本地验收的历史证据，不改写成 GitHub CI 的证据。该目录的源文件清单与本次复制的业务代码、测试、脚本、启动文件和依赖说明逐文件匹配；新增的 GitHub 工作流和发布说明不属于原清单。

Windows 工作流使用 Python 3.14，运行核心自检、完整 unittest（包含实际 Tk 回调、临时 SQLite 和异常退出恢复）及编译检查。运行结果以 GitHub Actions 对应提交的完成状态为准。截图检查使用可选 Pillow，仅有本地截图证据，不在此工作流中运行。

所有测试牌面和界面演示均为自建数据。此次同步只交付 V0.1 手动记录闭环；概率/EV、识别、捕获、规则纠错分支与实盘适配的未支持边界保持原样。
