# 静止牌角与持续观察：独立时序对照

静止牌角可能被旧的像素去重策略长期挡在“稳定”之外，这个问题已复现。但独立对照没有证明它是当前识牌失败的主要原因：完全相同的识别记录重放后，正确稳定覆盖仍为 18/31，仅部分 2 秒内结果改善；两轮实际窗口也没有整体提升。因此新策略仅为显式实验，默认策略保留。

## 改动和边界

代码 `e2df32e1a5538644297ff046178103a48a9f4a64` 增加 `--temporal-policy current-observations`。旧 `distinct-crops` 默认保持不变。新策略把当前新画面中的持续观察与不同像素的独立支持分开记录：同一牌角摘要仍只算一份像素证据，持续收到的新源画面可形成一致性显示，状态标明 `persistent_current_observation`，不把重复像素称作独立概率票。

两者仍拒绝整份源采样重复刷新状态，保留 550 ms 牌级过期、650 ms 身份过期、800 ms 窗口、冲突撤销及输入中断保护。新观察缓冲最多 8 项；同级两张牌保持分别关联。稳定显示不写账本，也没有新增自动确认。

合成正确 K：整图不变时仍不稳定并过期；全图更新、局部 K 像素不变时，旧策略 8 秒不稳定，新策略可在 250 ms 稳定，独立像素支持仍为 1。此前真实记录中找到 27 段满足三次连续接受且跨度至少 200 ms、却未稳定的轨迹/牌级片段，其中 24 段在首个符合点没有新增像素支持。这些片段不是独立牌，也不保证牌级正确，不能用它们解释全部漏识。

## 固定输入重放

为排除两轮操作系统调度采样不同，使用默认轮记录的相同源时间、推理结果、裁片摘要、关联 ID 和绘制时间重放 `_observe`。默认策略的 7,672 个轨迹快照全部复现，默认事件指标也复现。固定这些输入切换持续观察策略：正确稳定仍 18/31、错误稳定仍 3，1 秒仍 8–10，2 秒由 11–12 变为 13–14；条件 P95 不变。额外稳定代表由 14 变为 16，尚未全部判真伪。

这是离线反事实重放，不是另一次实际 GUI 或 WGC 性能测量。第一次重放错误地在空闲提交时刻老化状态，导致默认显示复现失败；失败文件保留。第二版用原快照的 `last_seen_ns + age_ms` 恢复实际绘制时钟，同一绘制各轨迹核对到 1 ns 内，再保留原提交时钟计算延迟。没有改写原运行记录。
