# FLOW-3：稳定录牌区与显示偏好

牌面键默认常驻，普通录牌不必打开设置。数字键区、常用动作区、阶段主操作区分开，阶段变化和概率失效不会用“结算”替换原来的牌面位置。键盘用户可“收起牌面键”，当前发牌对象和最近输入仍保留。改牌表单就地覆盖结果区，避免把牌面按钮推向另一位置。

“录牌设置”只展开低频模式、完整录入提示和设置。简洁态、设置展开态、工作台分别记住用户尺寸，切换后恢复，重新启动仍有效。窗口按所在显示器的可用区域限制大小；小屏或较短窗口使用滚动条访问完整内容，不缩小字体或删除必要说明。

显示偏好存在所选数据库旁的 `.ui-preferences.json`，只含版本、各视图宽高、是否显示牌面键。它不保存桌规确认、非BJ事实、分析对象或实际动作。未知/损坏偏好保留原文件，忽略它使用默认布局；偏好保存失败不影响记账。

Enter/Tab继续导航，Space继续暂停录入，不承担结算开轮。原生 Computer Use 在独立模拟数据库实测改6为5、停牌、8揭示/3补牌、双击收尾只生成一个新轮、设置展开收起恢复尺寸、键盘模式保留当前对象。完整测试覆盖尺寸往返/重启、实际Tk焦点事件、屏幕边界和滚动、坏偏好保护，既有数学/暗牌/多人假设回归保留。
