# FLOW-2：最近可见牌改牌和明确撤销对象

小面板显示本轮最近可见牌的座位、手牌、张序和当前牌面。点击“改牌”就地选择正确牌面、快捷原因和可选补充说明，再点击“保存改牌”。不必选时间线，不弹两个输入对话框。自动暗牌虽然可能是最后一条事件，但不会成为最近可见牌；它关联的触发明牌仍可修改。最近输入为揭示时，修改对应揭示事件。

纠错继续通过原有 CORRECTION 追加及完整账本重放路径。容量、分牌资格、终局牌序、非BJ事实和后续事件冲突均拒绝保存，错误显示在改牌区。编辑期间的记录变化会使旧编辑目标失效；编辑字段保留正常键盘行为，外部录牌快捷键不会误写牌。明确保存后才恢复普通录牌。

只有身份、完整前缀和已处理牌集合一致的正常计划可保留录入位置；牌面变化后重算阶段和实际非BJ门禁，不生成检查事实。未知/人工核对状态继续暂停。已保存的历史判断和原始事件保持不变。

撤销依然逐事件追加，按钮依据同一套有效事件顺序显示“撤销自动暗牌”“撤销底牌揭示”“撤销本次纠错”等。没有引入组撤销。

专项测试覆盖触发明牌、揭示、历史前缀、恢复、分牌/非BJ冲突、牌靴容量、保存失败、旧编辑器与真实Tk按键、撤销对象，以及与原时间线纠错的概率、EV和组成一致性。
