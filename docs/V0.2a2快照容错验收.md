## 数据边界

- `load()` 在摘要操作、历史排序和界面取值之前检查根对象、result/input 对象、文件身份、输入身份、保存时间及显示字段。
- 格式错误统一为 `SnapshotFormatError(ValueError)`；`list()` 只按文件接住该错误及文件读取错误，不吞任意编程错误。UTF-8/JSON 语法错误、数组/空值/其他标量根、嵌套类型错误、缺字段、非有限或不可显示的时间均可隔离。
- 旧存储 API 接受的最小 `{schema,input,input_digest}` 结果信封仍可保存、加载、枚举。它没有完整计算身份，界面标明“仅存储信封”，禁用复算；不会给它补造牌面或 EV。
- 旧引擎版本的完整快照仍可读，按原事件前缀复算仍另建文件。
- 存储预留 `hakimi-analysis-result-v2` / `hakimi-split-analysis-input-v1` 的共同身份及 hands 结构兼容。此独立 N1 界面尚无分牌展示器，因此 v2 暂作只读并禁用复算。分牌功能集成时应扩展 `DISPLAY_RESULT_SCHEMAS` 和 `format_result()`，以新分牌工作流测试替换当前“尚未安装展示器”的阶段断言；这不是分牌算法验收。
