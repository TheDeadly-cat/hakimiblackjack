# 顶部下一轮投注EV估算

顶部标题区新增“下轮EV估算”：每1单位底注的预期净收益、优势率、95%抽样误差范围和正负状态。优势率就是净收益除以最初1单位底注，包含后续分牌、加倍的合计盈亏。点击标题可以查看本次剩余组成、人数、本人座位、样本和方法。

空牌盒建好后、尚未录第一张牌的本轮、或完整结束本轮后自动计算。开始录牌立即撤去旧值，进行中的牌局显示等待；未揭暗牌、未知烧牌、观察缺口、此前轮次观察完整性未知、剩余牌不足或不支持的桌规均不填数。撤回后按新账本前缀重新判断。主界面“取消”同时取消开局和手牌分析；开启下一次录牌或明确重试后再计算。

支持当前常用模型：S17、3:2、美式底牌及玩家动作前检查BJ、任意初始两张加倍、同值最多两手顺序分牌、无再分、分A只补一张、分牌后不投降，原手无投降或late晚投降。DAS允许或禁止均可。旧same_rank、H17或其他组合保持明确不支持，不按相近模板猜测。

计算按实际剩余十种点值组成，每轮从同一组成独立重新洗牌、不放回发牌。按当前设置的1～7人及本人位置发初始牌，其他玩家也使用同一固定策略；他们的补牌会消耗同一副剩余牌并影响庄家。模拟原手天然BJ、BJ检查、晚投降、分牌、分后加倍、软硬点数和庄家S17，结果以本人最初1单位底注为单位。

固定策略先由开局组成推导：用同组成的放回模型求停牌／补牌／加倍／投降／两手分牌的动作值，在整轮内固定使用；不查看模拟中的实际隐藏底牌，也不根据后续未公开牌改策略。实际收益评估使用有限不放回模型。它估计的是这套声明策略的EV，不是有限牌盒最优策略，也不等于当前手的最佳动作EV。

每次固定200万轮，输入、策略版本和种子绑定。相同组成及人数／本人位置重试使用相同种子，撤回不能靠不断重采样挑出正值。只有完整样本返回才发布；超时、耗尽或取消不发布部分结果。原始半单位收益直方图在Python端重新核对样本数、均值、方差和区间，结果必须与当前会话、牌盒、账本前缀、桌规及模型身份一致。

误差采用[Maurer与Pontil（2009）定理4](https://arxiv.org/abs/0907.3740)的经验Bernstein界，将收益范围缩放到[-4,4]并对两侧使用联合界。半宽为`sqrt(2*s²*ln(4/δ)/n) + 7*8*ln(4/δ)/(3*(n-1))`，δ=0.05。区间全部高于0才标“正EV估算”；全部低于0标“负EV估算”；跨0标“正负待定”。这是每次固定策略估算的抽样区间，不覆盖记录错误、桌规错误或策略选择差异，不是盈利保证。

开局模拟在独立可取消进程中运行，复用原有Windows进程归属和编译回执机制。原精确手牌求解入口不使用抽样；同一数值程序通过独立请求类型选择开局模式。标题保留固定高度，结果变化不会移动牌面键。开局结果不写入牌面账本，也不伪装成历史手牌快照。

自动验证包括：1张A＋3张十点牌的全部24种物理顺序，精确期望为+0.25；十种纯点值牌盒的确定收益；多人共享牌盒、DAS注额支持、样本耗尽、输入资格、未知牌阻断、撤回及恢复、伪造数值／正负标记／旧前缀拒绝、取消及标题位置稳定。具体测试和实际界面验收以对应提交日志为准。
