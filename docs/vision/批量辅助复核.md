# 批量辅助复核

用户检查预填结果，无需从空白页逐张画框。它适用于本机录像的辅助标注，不会训练或替换运行模型，也不会写入记牌账本。

## 准备

先用 `scripts/video_to_material.py` 转成带来源摘要的本地素材会话，再为每段生成新的标注文件：

```powershell
python scripts/prepare_assisted_review.py .local-evidence/session .local-evidence/review.json --model .local-evidence/annotation-helper-model --step 20
```

`--step` 是素材清单的帧间隔，不是原视频的帧间隔。素材每 2 秒采样、step=20 时，检查页面约每 40 秒一张。原帧和遗漏不等于全部视频帧已经标注。

`--original-annotations` 可传已有标注：已完成页和已有框的页面完整保留，包括用户画框、标签、编号与复核记录。输出必须使用新文件。来源不匹配、帧内容改变、素材截断或输出已存在都会停止处理。

可选 `--empty-background` 接受人工选定的同尺寸空桌 PNG，用局部图像匹配标出静态背景候选。该结果仍是待确认建议。候选编号自动生成，只标识这个框，不能证明同一物理牌，也不能替代跨帧身份复核。

批量清单示例（实际路径填写本机路径）：

```json
{
  "schema": "assisted-review-bundle-1",
  "default_reviewer": "",
  "sessions": [
    {
      "title": "录像一",
      "session": "C:/local/session",
      "annotations": "C:/local/review.json",
      "source_sha256": "素材 manifest 中的 source_sha256"
    }
  ]
}
```

```powershell
python scripts/review_assisted_batch.py .local-evidence/bundle.json
```

## 检查

- 顶部切换录像；上一页、下一页或下一待核页切换页面。已完成页默认跳过，但仍能查看。
- 点击图中框或列表行查看周围牌面。按 2–9、A/J/Q/K、0=10、N=非牌、U=待辨认即可改错并保存；Enter 接受当前项并移到下一项。
- 点击“整页通过（含非牌）”或 Ctrl+Enter，明确确认整页的所有框并进入下一待核页。默认隐藏非牌框，可勾选“显示非牌框”检查。
- Del 删除误框，Ctrl+Z 撤销最近操作（本次打开内保留 40 步）。少量漏框可用“补漏框”，不用输入编号。
- 只有用户主动确认才写 `human_reviewed`。AI 检查仍是 `assistant_proposed`；原建议和修改后的标签分别保留。匹配度来自原模型，不是 AI 修正标签的正确率。
- 如文件被另一个程序改动，停止覆盖并撤回内存中的本次操作。重新打开后读取最新版本。

## 正向上角复核口径（2026-09-13）

按用户的新要求，本批复核及后续素材预标注只取每张牌上方或左上方的正向点数，不把倒向/下半角标翻转后再次识别，也不在上角缺失时用下角补数。这里调整的是辅助复核清单；该清单的筛选和点数建议仍待用户检查。

先生成新的上角批次，原目录和确认记录不被覆盖：

```powershell
python scripts/prepare_upper_review.py .local-evidence/bundle.json .local-evidence/upper-review
python scripts/review_assisted_batch.py .local-evidence/upper-review/bundle.json
```

自动位置建议使用每个候选附近的牌体边缘，不是按整幅截图的上下半区裁切。叠牌和斜牌可能使边缘判断不确定，需要对照原图；不确定位置默认排除。可以通过 `--decisions` 提供已对照画面的筛选建议，键绑定视频摘要、帧摘要及原框，值包含 `keep`、可选新框 `bbox` 和点数建议 `rank`。已有的人审点数不会被建议覆盖；调整后的框单独标记助手来源。

排除项保存在每帧的 `excluded_objects`，包括原点数和复核信息；点击“查看排除项”可检查、恢复误排的框，无需重画。恢复不会自动确认标签，操作可撤销。窗口会优先打开有待核点数的页面，逐项确认后自动跳过已核标签；空候选页仍保留待核状态，不会自动宣称人审完成。

本机对原有 1,313 个非牌以外的候选查看了放大上下文，并补定位原有整牌人审框的上角。新批次保留 557 项，另存 1,834 项排除记录。用户已有 261 条确认全部保留：94 条在活动清单，167 条在排除清单，点数、复核人和复核时间均核验一致。第一段从第 14 页继续。各版清单及逐项筛选决定保存在本机忽略目录 `upright-review-20260912` 下，不进入源码仓库。

新增 12 项工程测试覆盖按每张牌取上角、无下角回退、同点数不合并、人审数据保留、恢复/撤销及续审位置。旧人审点数和助手新裁框分别记录：新裁框未经用户主动确认，导出的训练裁片仍是助手建议。窗口用副本验证四段切换、修改/撤销、排除项恢复/撤销。原帧漏检和标签正确率不能由这些测试数量推断。
