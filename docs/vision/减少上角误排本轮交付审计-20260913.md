# 减少上角误排：本轮交付审计

本轮任务是保持点数模型权重和分类门槛，定位并减少真正上角被误过滤，随后做可追溯的真实材料检查。原任务的交付条款明确接受“有效的完整子集或 valid=false 的局部诊断”；几何改善不足时要求“先提交错误分型和小模型替代对照设计，不继续无限追加启发式”。

本次采用允许的**局部诊断交付分支**。下面核验的是这轮有界整改、运行检查与证据交付；完整连续识牌、独立真值验收及自动化升级均未通过。不能把这些未通过项改成通过，也不把后续原型训练追加为本轮结项条件。

## 必须保留的解释边界

真实 A/A 分牌已经找到并检查，不能再写“现有录像缺少分牌素材”。实跑后的结果仍不支持完整身份/归属验收：分牌后两张 A 的上角进入几何待核，补牌后被遮住的上角不以下角代替。该失败本身已经记录在允许的局部诊断交付中。

原任务没有给出必须达到的完整帧识牌率、自动入账条件或强制通过的连续准确率阈值。本轮没有把工程通过解释成这些能力已经成立；也没有以缺少最终独立人审真值为理由丢弃现有素材或无限继续这轮几何调参。

后续明确的一步是使用现有原图整理可用的几何类别增量，按已交付的单一对照设计开展下一阶段实验；点数权重、门槛和原记录继续冻结。该后续计划与本次局部诊断交付分别记录。
