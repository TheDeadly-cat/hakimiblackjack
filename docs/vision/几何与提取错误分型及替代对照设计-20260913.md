# 几何与提取错误分型及替代对照设计

原 25 页上的有界改动已将已知目标正确输出从 62 增至 70，仍不足以完成可靠连续识牌。原有 48 项诊断和旧模型保留；后续实验要区分错误阶段，不能把所有漏识归为同一种几何问题。

## 当前证据支持的错误分型

| 类别 | 已有真实证据 | 对下一轮设计的约束 |
|---|---|---|

这些类别可以共存，同一事件不强行分配唯一根因。助手分类与人审记录保持各自来源；不直接用本轮错误反写当前模型的训练答案。

## 唯一下一步：固定候选集的小型几何对照原型

先实现一个只决定“上角／下角／非牌／不确定”的小型候选评分原型，保持点数权重、点数门槛和原始候选提取不变。该原型尚未训练或接入当前运行；以下是实验设计，不是能力交付。

### 固定输入与三个对照

A 为原垂直几何，B 为 `upper-upright-local-2`，C 为一个带正则化的多类线性候选评分模型。C 同时读取候选附近原始图像的边缘/颜色上下文与现有牌体几何特征，避免只复制容易突变的填充掩膜。原始点数假设、人工答案、未来帧和已知牌面均不得成为 C 的输入。

候选上下文在原图坐标中固定裁取，保存实际尺寸及变换。只为特征编码统一尺寸，不改变点数模型输入，不把重采样称为更高的真实录像分辨率。不得加入 180 度翻转或使用倒置下角补数。

在同一候选列表上比较三个方法，输出模型/数据摘要和四类结果。只有确认上角进入原点数分类器；不确定项保持独立证据，不生成点数、身份或入账候选。C 不得凭本轮 K/7 参考框额外生成原提取器没有的候选。

### 数据与冻结顺序

复用已有原图和标注，保留 559 条原人审及 41 项新框确认。点数确认与几何方向确认分开：旧记录里仍有对侧角标、侧向和未验证身份，不能一律变成已确认上角。先整理来源清楚的几何类别增量，助手建议单独保存，缺少相应人工方向确认的条目不冒充已确认训练标签。

按照源片段、连续物理事件和内容重复组隔离数据；帧号不同不等于不同牌。同一组时间邻近裁片不得分散到训练与验证。冻结一次训练/选择计划，并确保验证包含真实下角、花色、印刷字、残片与负例。已有 105 条训练负例不作为独立测试负例。

现有录像可继续用于整理候选和方向增量，不先要求新录几十小时。最终独立性需具体记录片段与实际事件关系；来源关系不明确时，结果保持开发诊断。小窗口冻结片段已经用于此次检查，后续不能反复调它再叫新盲测。

### 必须报告的结果与停止条件

在冻结的完整开发对照上报告 raw 数、进入点数分类的数量、正确、错误、拒识、未匹配、非牌误收、下角误留和不确定项数量。针对原 48 项逐项保存前后对应；候选数量增加不算正确覆盖提高。没有完整原帧真值时，保留 `valid=false` 和空的正式指标，同时报告局部诊断。

在连续片段上同时报告错误合并、身份断裂、跳变和未测事件。分牌、归属或揭牌没有实际证据时写未测，不用别的事件代替；工程测试与实际录像分开列出。候选试用不开放自动入账。

只做一次预先指定的 C 原型及冻结选择过程，不无限搜索规则、模型或超参数来追当前答案。如果原始候选覆盖仍是主要限制，保留 C 的结果，再单独立项比较候选提取；不要在同一次实验里同时改变提取、几何和点数模型。后者需要独立版本、输入契约、候选身份与来源/尺寸对照，不能悄悄合入 C 后宣称是几何改进。
