# V0.3a 能力与不支持

日期：2026-09-12  
声明：这是**自建 synthetic-felt-v1 的离线识牌首版**，不是通用 OCR，也不是真实牌桌识别。

## 能做

- 打开本地 PNG/JPEG，在冻结的庄家/玩家1 区域内出 13 种原始点数候选。
- 空区、牌背、遮挡角标、非绿绒面不作为已接受点数。
- 人工确认/改正/拒绝后，经控制器写入现有账本；拒绝不写。
- 同一确认请求幂等；两张 8 是两张牌；揭示走 `reveal`，不二次扣牌。
- 未确认时界面写「图像待核对」，旧 EV 不得当作已考虑本图。
- 未安装 OpenCV 时，手动录牌、对照实验和 `python -m blackjack_lab.main --check` 仍可用。

## 不能做 / 未声称

- 真实平台、直播、相机、授权窗口捕获、自动下注。
- 把匹配度当成正确概率，或按模型分数自动扣牌。
- 视觉层输出 T；十点未细分只能由人确认后记入账本。
- 三/六整轮模拟、下一轮开局优势、多玩家 EV。

旁观录像（打开本地文件、暂停、跨帧去重、开靴三态）见 [V0.3b-旁观录像.md](V0.3b-旁观录像.md)。仍不开发录屏器，也不把多人识别当成多人 EV。

## 样式

只验收 `synthetic-felt-v1`。`platform_claim = none`。
