# V0.3e 标注 + 训练 + 留出集评测

日期：2026-09-12  
范围：在真实全屏牌区裁片上做**人工标注 → 小型分类器 → 按局留出评测**。  
不打开自动确认，不写账本，不引入 torch / YOLO。`platform_claim = none`。

V0.3d 已证明连通块 + 模板匹配分不开 13 点。本轮把文档里说的「先要有标注集」落成可重复闭环。

## 闭环

```
capture_material.py          只存牌区，按白像素跳变取样
        ↓
prepare_glyph_queue.py       抽出字形裁片，整局切分成 train / holdout
        ↓
label_glyphs.py ui | apply   人标 13 点数或 junk（花色/绒面字/牌背）
        ↓
train_rank_classifier.py     只在 train 上拟合 numpy kNN；只在 holdout 上出原始预测
```

切分规则（`fixtures/README.md` 第 3 条）：

- 按**整局**切，最后 30% 局进留出集。
- 同一帧签名、同一裁片、同一局不得同时出现在两侧。
- 看不清的不标，不把模型分数回写成标签。
- 原视频 / 整屏 / 余额聊天不入库；队列在 `.local-evidence/`。

本机 OpenCV 5.0 没有 `cv2.ml` 和 `HOGDescriptor`，分类器是 32×32 HOG + numpy kNN。分数不是校准概率。

## 本机第一次实跑（不是验收通过）

素材：`.local-evidence/material-train-20260912`（20 分钟、1825 张牌区 JPEG，不入库）。  
取样：35 局各 1 帧（该局白像素最多的瞬间）→ 258 个连通块。  
标注：156 / 258（拼版图上能看清的才标；Q 一枚都没有）。

| | 训练 | 留出 |
|---|---|---|
| 已标注 | 93 | 63 |
| 可辨认点数 | 74 | 57 |
| junk | 19 | 6 |

留出集**原始预测**（人工事后改的不算模型成功）：

| 指标 | 数字 |
|---|---|
| 接受项 13 点数准确率 | **0.857**（24 / 28） |
| 端到端可辨认召回 | **0.421**（24 / 57） |
| 接受但认错 | 4（3→J，6→9，10→8，K→5） |
| 可辨认但拒识 | 29 |
| junk 误当成点数 | 1（→K） |

训练集自检接受项准确率 1.0、召回 0.61，只说明过拟合，**不是验收**。  
训练里 A / 10 各 1 张，Q 为 0，这些点数的留出数字不可外推。

**自动确认仍关闭。** 0.86 的接受项准确率加上 0.42 的召回，离可用还差一截；错认会直接写错账。

## 第二轮（补训练局，留出 63 条冻结）

`--append --per-round 3` 只加训练局，留出裁片与标签不动。训练标注 93→196。  
6/9 不再做 180° 增强。门槛只在训练局内部选（vote≥2, margin≥0.02）。

| 指标 | 第一轮 | 第二轮 |
|---|---|---|
| 训练已标注 | 93 | 196 |
| 留出已标注 | 63 | 63（冻结） |
| 接受项准确率 | 0.857（24/28） | **0.804**（37/46） |
| 端到端召回 | 0.421（24/57） | **0.649**（37/57） |
| 接受但认错 | 4 | 9 |
| Q / A / 10 训练数 | 0 / 1 / 1 | **0 / 1 / 2** |

召回上去了，错认也多了。6 不再被当成 9，但 9 仍有 2 次错认。Q 仍然没有进入训练集——桌上的 Q 经常抽不进连通块。  
**自动确认仍关闭。**

## 命令

```
python scripts/prepare_glyph_queue.py .local-evidence/material-train-20260912
python scripts/prepare_glyph_queue.py .local-evidence/material-train-20260912 --append --per-round 3
python scripts/label_glyphs.py ui .local-evidence/material-train-20260912/glyph-queue
python scripts/train_rank_classifier.py .local-evidence/material-train-20260912/glyph-queue
python -m unittest tests.test_vision_rank_classifier -q
```

另采一个会话做留出时：

```
python scripts/train_rank_classifier.py <训练队列> --holdout-queue <另一会话队列>
```

## 测试在证明什么

`tests/test_vision_rank_classifier.py`：整局切分、帧泄漏拒绝、合成点阵（无 180°，避免 6/9 互换）上分类器能分开 13 点、未标注样本不计入评测。  
它**不**证明真实牌桌已经可用。

## 还不支持

- 没有接到核对窗 / 实时捕获的自动接受。
- 没有第二会话留出（本轮是同一 20 分钟里按局切开，比随机拆帧诚实，仍不如另采一段）。
- Q 未入训练；A / 10 样本不够。
- 点数与花色黏连、6/9 倒置仍是错误来源。
- 不宣称对任何平台的识别能力。
