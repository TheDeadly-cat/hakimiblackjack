# 指定模型、回放与实时候选

模型必须显式选择，样式 JSON 的 `style_id` 必须与模型 manifest 相同。旧版无完整身份的模型需要重新训练；加载失败不会悄悄换回模板。界面和结果标明 model_id、模型摘要、特征与提取器版本、训练摘要。当前均为开发候选，自动确认关闭。

## 安装

```powershell
python -m pip install -r requirements-vision.txt
# 仅在需要 Windows Graphics Capture 时另装：
python -m pip install -r requirements-capture.txt
```

两份依赖共用 `opencv-python==5.0.0.93`、`numpy==2.4.6` 和 `Pillow==12.2.0`，捕获再加 `windows-capture==2.0.1`。不要同时安装 `opencv-python-headless`，它与 `opencv-python` 写入同一个 cv2 命名空间。建议在新虚拟环境安装；本轮未卸载或改写用户已有环境。

## 本地图与录像

以下路径仅为示例，换成自己的本地材料；模型目录内须有 `manifest.json` 和 `model.npz`。样式可为静态布局 JSON 或归一化 LiveStyle JSON。

```powershell
python scripts/vision_demo.py .local-evidence/frame.png --model .local-evidence/model --style .local-evidence/style.json --json .local-evidence/candidates.json
python scripts/vision_demo.py --gui --model .local-evidence/model --style .local-evidence/style.json
python scripts/probe_navy_live_video.py .local-evidence/video.mp4 --frame 100 --model .local-evidence/model --style .local-evidence/style.json --output .local-evidence/replay-probe
```

主窗口的“识牌核对”也可选择样式/区域 JSON 与模型。切模型、来源或区域后撤回旧候选；新一帧不展示旧帧裁片。确认后仍由原控制器写入账本。

新一局必须先在主窗口结束旧轮并开新轮，再点“绑定到当前轮（确认新轮）”。这是明确的人工轮界：同位置的新牌会取得本轮新身份，旧轮已确认轨迹仍保留。短暂漏检、空牌区或经过很久本身都不会自动遗忘旧牌，防止同一张牌再次扣除。

## 授权窗口捕获探针

复用现有 WGC 采集器和 FrameIntake；`--style` 必须是归一化 LiveStyle JSON，区域相对捕获后的画面。若样式已有 `capture_crop`，不要重复传 `--crop`。

```powershell
python scripts/live_capture_probe.py --list
python scripts/live_capture_probe.py --window 12345 --seconds 10 --model .local-evidence/model --style .local-evidence/live-style.json --output .local-evidence/live-model-probe
```

默认不保存画面；`--save-frames N` 才保存选定区域的前 N 帧。回执包含模型身份和候选计数，`latest-candidates.json` 保存最后一帧候选。静止重复帧或黑帧不会增加独立识别帧计数。区域/尺寸/采集代际变化后旧推理结果被丢弃。

捕获运行成功、候选计数和 CI 通过都不是实际识牌准确率。CI 单独安装可选视觉依赖，验证合成图、临时数据、模型切换与人工确认契约，不安装 WGC、不使用真实素材。真实漏检、错认、物理牌身份与归属仍须独立会话原帧人工真值评测。
