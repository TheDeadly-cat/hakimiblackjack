## 样式

`synthetic-felt-v1`，详见 `fixtures/vision/synthetic-v1/STYLE.md`。
`platform_claim = none`。

## 运行上限（已冻结）

| 项 | 值 |
|---|---|
| 最大文件 | 20 MiB |
| 最大边长 | 4096 |
| 最大像素 | 16_000_000 |
| 队列 | 1（单任务） |
| 输入 | 本地 PNG；JPEG 需 OpenCV |
| 远程 URL / file: URI | 拒绝 |

## 依赖

未安装时：`python -m blackjack_lab.main --check` 与手动录牌不受影响。
