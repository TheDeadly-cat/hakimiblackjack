## 本次关联改动

当一条现有轨迹的原位置仍有同帧、同模型的几何待核框时，附近的新观察不能仅靠中心距离接走该 ID。真正与原轨迹框重叠的观察仍按原规则关联；没有这个空间冲突时，原来的移动/分牌距离关联保持不变，沿用既有 IoU 门槛，不另调参数。

待核框只提供这一否决条件，不作为检测输入，不更新旧轨迹的位置、点数或出现时间，也不创建轨迹、分类结果或账本候选。跨帧/跨模型的旧待核项及带有已分类/入账标记的项不会参与保护。
