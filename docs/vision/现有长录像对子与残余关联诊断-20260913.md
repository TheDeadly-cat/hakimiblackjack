## 残余 7/K 身份串用的具体原因

在 21:12 录像的第 12,500–12,740 帧，重新执行真实图像分类，共 241 帧。使用上一轮逐帧 trace 恢复此前轨迹状态后，每一帧的源像素摘要、预测点数、候选框和关联 ID 都精确复现当前版本。运行约 26.337 秒，退出 0。这是诊断执行成功，正式连续验收仍不成立。

进一步检查原始图像和八帧逐阶段提取结果，得到比“7 被手挡住、K 抢走 ID”更准确的原因链：

| 源帧 | 实际输出与关联 |
|---|---|
| 12,655 | 7 的原始连通块、上角判断和点数输出仍存在，框 `[1013,257,27,20]`。 |
| 12,656 起的已检查关键帧 | 原图中的正向 7 仍可见，但原始提取结果中没有与旧框相交的连通块；它没有进入几何待核列表。 |
| 12,695（约 105.792 秒） | 新 K 的角标已经产生候选，但点数尚为拒识。该候选框 `[1033,223,40,20]` 与旧 7 框的 IoU 为 0、中心距离约 43.107 像素，距离关联将旧 ID 交给它。 |
| 12,696 | K 被分类器接受。此时前一帧的轨迹框已移至 K，IoU 约 0.909，继续沿用同一 ID。 |
| 12,740 | 旧 7 的原始提取框重新出现，但先前 ID 已跟随 K。 |

这里的缺口发生在原始提取之前/之中，并非这一刻上角策略把 7 判成下角。当前待核位置保护只能处理“还有几何待核框”的情况，无法保护根本未进入提取结果的位置。此处没有进一步断言是哪一个像素处理步骤导致连通块消失。

简单增加“本帧点数与旧点数不同就新建身份”也不能覆盖这个事件，因为串用发生时，新候选还未识出点数。不能据此将所有拒识框都视为新牌：花色、噪声和同一张牌的抖动也会拒识。

保留该事件作为提取稳定性和移动关联的反例，不为这一张牌继续堆几何阈值。下一步若实验外观连续性，应只作为身份关联证据，另行冻结对照范围，报告错误合并与轨迹断裂两个方向的结果；不能把旧点数补进当前不可辨认帧，或把拟议方案说成已经实现。
