# 人审完成后的正向上角模型

四段录像的 559 条活动标注都已有人工点数确认，已经按原字节备份并生成新模型。在同一组 164 条开发留出裁片上，旧模型识对 44 条，新模型识对 87 条；错认从 8 条降到 7 条。回到原截图后仍有明显取框遗漏，当前结果只支持开发候选，不构成完整视频验收。

82 张原 PNG 内容摘要与标注一致。跨组的原帧、裁片、二值掩膜、来源和已知身份重复检查通过，`first-split-audit.json` 保留首次结果。训练集覆盖全部 13 点数，每类 8–22 条。仅第一段参与拟合，第二段用于 32 组门槛比较，后两段不参与训练或门槛选择。

四段都已用于助手预标注和用户复核，不能称为未查看的盲测；分开的录像文件也不能单独证明不同牌靴或事件独立。原有候选编号不自动升级为已验证的跨帧物理牌身份。页面大约每 40 秒抽样，空页和整帧完成标记未被自动补齐。

## 模型和运行规则

新模型保存在证据目录的 `upright-training-run/model/`：

- ID：`rank-knn-617ba2adc6f1fc3207362da156274a84a06ce939a4d7b7f53c8bfc8526d3e030`
- 模型文件 SHA256：`b9fc805cf9a50aa8159f0718bcdcdee49722be7996a277537e1107adaf034be2`
- 训练摘要：`bc988f0ee094befe12cabc79855153828a3c724ff77e55f244d9dc2d781cf5ba`
- `orientation_policy=upright_upper`，`label_review_status=human_reviewed`。
- k=3，独立来源票数至少 2，竞争类别差值至少 0.02，相似度至少 0.85。相似度不是正确概率。

方向策略绑定模型身份并随模型保存、加载。新模型训练和默认推理只搜索 0、±15、±30 度，明确拒绝倒向增强或翻转推理。图片、录像回放和实时帧入口共用模型适配器，先依据每个候选附近的牌体边缘筛选上角，再分类；下角或边缘不确定候选不作为补识别来源。叠牌、斜牌的几何筛选仍会误排或误留，不能据此保证每张物理牌恰好一框。

旧 v3 模型保持原身份和方向行为，新代码可以继续加载。新模型没有覆盖旧模型或成为默认运行选择；所有输出继续等待人工确认，不自动入账。

## 同题裁片结果

两版均评测相同的 163 条点数和 1 条非牌。拒识也保留在可辨认点数的分母中；人审点数仅作答案，不改写预测。

| 指标 | 旧 v3 模型 | 新人审正向模型 |
|---|---:|---:|
| 识对 | 44 | 87 |
| 错认 | 8 | 7 |
| 可辨认牌面拒识 | 111 | 69 |
| 非牌误收 | 0 / 1 | 0 / 1 |
| 输出中正确比例 | 84.62% | 92.55% |
| 全部点数裁片中识对比例 | 26.99% | 53.37% |

选择门槛所用的第二段：107 条识对、7 条错认、75 条拒识。该组无非牌，留出组也只有 1 条非牌，尚不能验证一般背景误报率。训练自检的 121 条识对没有并入留出成绩。

新模型的 7 条错认分别为 J→3、3→8、9→6 两条、J→4、5→8、6→9。13 点样本已经补齐，但 7、A、10 等仍有较多拒识。完整逐项预测、每类统计及混淆矩阵见 `upright-training-run/holdout-report.json`；旧模型对照见 `baseline-same-holdout.json`。没有据留出错误重新调参或改人审答案。

## 原截图检查与工程验证

使用相同后两段的 25 个抽样页面，对已审核上角进行几何匹配：163 个已知点数目标中 62 个识对、2 个错认、51 个拒识、48 个未匹配到提取框。此处经过实际取框与上角筛选，不能用裁片的 92.55% 代替这一层表现。由于页面并非完整的原帧真值，评测如实返回 `valid=false`，完整 precision/recall 留空；未匹配的其他输出不能直接认定为非牌或正确牌。报告为 `upright-partial-frame-3.json` 和 `upright-partial-frame-4.json`。

另将两张真实录屏 PNG 分别送入图片、回放、实时帧数据适配入口，三路候选、点数和模型身份一致，未写账本。这是本地文件的接口检查，没有启动 WGC 捕获。上角筛选使用 `navy-components-border-3+upper-upright-corner-1`，摘要绑定该版本。

工程测试新增 6 项，覆盖方向持久化、拒绝翻转覆盖、身份篡改、旧模型兼容、下角不送入分类器、同点数上角保留和人审输入限制；已有门槛选择测试补查方向策略传递。可选识牌组 239 项通过。首次本机全组运行有 1 项错误：仅父进程使用 `-X utf8`，子进程输出编码不同；保留首轮日志后，使用与 CI 相同的子进程环境 `PYTHONUTF8=1`、`PYTHONIOENCODING=utf-8` 重跑通过。后续针对最终测试修改的 23 项检查及编译通过。工程通过不代表真实录像准确率验收。

下一步应依据已冻结的已知上角分析提取遗漏、叠牌和斜牌，另行形成新开发实验；本轮模型与评测先固定保存，避免边看留出答案边修改同一份成绩。
