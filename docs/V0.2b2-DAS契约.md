## 每手状态

每手在参考输入中至少包含：

- 已见牌 `ranks`
- 当前注额 `stake ∈ {1,2}`（分牌后初始 1，该手 DAS 后为 2）
- 是否已加倍、是否等待唯一补牌、是否闭合
- 当前行动手；第二手在首手完成前只有分得的那一张，不得预看未来牌

强制补牌：

- 分牌后单张：只能 `deal` 第二张；该张到达后若非 A、未 21，仍可 DAS
- 已选加倍未收牌：只能 `deal` 那一张，然后该手闭合
- 已选普通补牌、当前已是两张：只能 `deal` 下一张；该张到达后不得 DAS（与直接录入第三张同一规则）
- 三张及以上：无加倍

## 投入（必须分开写）

相对最初 1 单位原注记账，退还本金不算盈利。

| 名称 | 含义 |
|---|---|
| `current_investment` | 已经下去的单位：分牌后至少 2，每手已 DAS 再 +1 |
| `additional_investment` | **当前这个动作立刻**再投入；仅 `double` 为 1 |
| `possible_future_additional` | 本动作之后仍可能追加的 DAS 上界：尚未轮到的单位注额手，加上**仍一张**或**仍可决策 DAS 的两张**当前手。`stand`/`hit` 放弃本手 DAS；`double` 已把本手计入 `additional_investment`；两张牌的普通补牌等待或 DAS 唯一补牌的 `deal` 不再把当前手计入此后可能。分 A 的 `split` 此后为 0。这是上界，不是已证明必发生 |
| 最终净收益 | 两手结算后相对原 1 单位的合计；范围由注额决定，最大 `[-4,+4]` |

分牌前比较若进入 DAS 模板，不得再把“分牌后总投入”写成固定 2 却在收益里混入两手都加倍的 +4/−4。分牌动作本身立刻 +1；之后每手 DAS 才追加。

## 支付支持

按该手当时注额：

- 未加倍手：`{-1,0,+1}`
- 已加倍手：`{-2,0,+2}`
- 联合格为两手净收益对，不是 b1 的九格 `{-1,0,1}²`
- 合计为两手之和；允许键是注额决定的子集，禁止出现该手注额达不到的格
- 首手加倍爆牌 −2 必须计入，不得在第二手决策时漏计或再扣一次

基本会计恒等式（结算函数与参考必须遵守）：

```text
(-2)+(+1) = -1    首手 DAS 爆牌 + 次手普通赢
(+2)+(+2) = +4    两手 DAS 全赢
(-2)+(-2) = -4    两手 DAS 全输
(+2)+(-1) = +1    一手 DAS 赢 + 一手普通输
```

## 无 DAS 剪枝与信息上界（保留 / 禁用 / 重证）

生产 `SplitEngine.cs` 中 `FutureInformationGainBound` 明确写了耦合失败时第二手净收益差至多 **2（无 DAS、无再分、普通 21）**。两手总值上界 `2-2p`、望远镜求和里的常量 2 同样以未加倍注额为前提。b1 调用保持该函数、跨度 2，不得改 b1 路径。

DAS 生产路径不得把上述常数 2 改成 4 后继续当同一条证明。T9 按每手后续最大注额 `S2∈{1,2}` 重做耦合失败界：失败时第二手净收益差至多支付跨度 `2·S2`（不可再加倍则为 2，已加倍或仍可 DAS / 分牌后即将可 DAS 则为 4）。一步失败概率上界（底牌撞上被移除牌，或后续抽到该牌）与 b1 相同，因此

`delta = (2·S2) · [1/(M-k) + (D_21(b)+D_17(u+1))/(N-k-L-1)]`，`I = min(2·S2, delta · D_21(h))`。

该界只用于 DAS 首手**补牌**相对停牌的剪枝；加倍是另一动作，按注额 2 单独求值。补牌后续不可再 DAS，单手 `1-2p` 仍可用并按当前注额缩放。64 张低硬和补牌弱支配停牌：在比较补/停时成立（两者都放弃加倍）；仍可 DAS 时继续单独比较加倍。参考实现不做这些剪枝，完整比较动作。

| 机制 | DAS 模板 |
|---|---|
| b1 `FutureInformationGainBound` | **禁用直接套用**；b1 代码保留给无 DAS 模板 |
| DAS `CoupledInformationGainBound(..., 2·S2)` | 按注额跨度重证后用于首手补牌 |
| 单手 `1-2p` 补牌上界 | 未加倍的补牌后续仍可用；加倍动作按注额 2 |
| 64 张低硬和下补牌弱支配 | 补相对停可保留；不代替加倍比较 |
| 闭合手相对可见组成的鞅：已闭合首手的条件期望不随第二手随机可见抽牌改变，故第二手可只最大化自身期望。生产 `ClosedFirstPlusSecond` 把合计 EV 写成 `stake1·Stand(s1)+` 第二手自有 DAS EV（`stake1=0` 缓存，不按每个首手点数重解）。联合分布：第二手已不可 DAS 且注额为 1 时，走 b1 `SecondDist`（庄家耦合九格）再按首手注额缩放第一轴；仍可 DAS 或第二手注额为 2 时按所选动作展开 `TerminalDas`/`SecondDistDas`。`canDas` 已关闭后的 `nCards` 不进缓存键。参考实现不做该分解。
| b1 无 DAS 生产代码 | **保留**；旧模板继续走旧引擎 |
