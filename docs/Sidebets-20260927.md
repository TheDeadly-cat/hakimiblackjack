# 庄家天然BJ与边注契约

基线6266af5。用户已确认完整开发，首先使用明确标注的自建研究配置；草稿保留，不合并main。既有C#主注、规则语义、预算、数据库结构和原历史不改写。

庄家BJ是独立快速标量：发牌前2AT/[N(N−1)]；明牌A为T/U，十点为A/U，U含未知底牌与未发牌；实际检查后0，揭示后确定0/1。明牌2～9的结构性0不依赖完整库存；查看指标不写检查事件，也不放开主注动作门禁。

边注使用原始13种牌面与4种花色。PP只看玩家原始两张；21+3加庄家明牌。每个物理发牌事件只扣一次，分牌/DAS不产生新的边注机会。缺花色不猜、不平均分摊；只限制相应边注，不阻止原主注和合格BJ。

自建研究赔付：PP完美/同色/混色25/12/6；21+3同花三条/同花顺/三条/顺子/同花100/40/30/10/5。A23、QKA成立，KA2不成立，按配置优先级只付一档。EV按各自1单位边注净收益，未中−1；净赢不重复扣本金，含本金返还先减1。research、unconfirmed、verified分别保存；研究EV标为研究，不是实际桌规已核对。未确认或缺失赔付EV为null，仍可提供已具备条件的概率。

关闭边注花色录入时保留原数字键方式。发牌前预测以原前缀冻结；开始发牌后仅可查看已封盘原预测和原始牌型的实际结果。后续补花色/纠错/规则调整不改原快照；原时点复算另存。结果存储与真实发牌事件分离，失败可重试，不回滚发牌。
