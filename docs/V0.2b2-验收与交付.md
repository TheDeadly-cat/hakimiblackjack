## 命令

```powershell
python -m unittest tests.test_das_pending_hit tests.test_das_workflow tests.test_das_benchmark_contract tests.test_das_history_roundtrip tests.test_das_release_gate tests.test_portable_copy tests.test_das_optimization_diff tests.test_portable_runtime -v
python -m unittest tests.test_experiments tests.test_experiment_ui -v
python scripts/das_benchmarks.py --output <新目录>
python scripts/das_ui_check.py --output <新目录>
python scripts/make_portable_copy.py --output <新目录> --require-clean
python scripts/verify_das_release.py --output <新目录> --matrix-dir <已跑过的336回执目录>
python scripts/run_experiment.py --mode synthetic --decks 6,7,8 --player 10,6 --up 10 --output <新目录>
```

`scripts/split_benchmarks.py` 与 `scripts/verify_split_release.py` 仍是无 DAS 的 b1 交付，不能换签为 DAS 成绩。336 矩阵、unittest 项数、旧 318 个 b1 冷请求是三份不同证据。

`--matrix-dir` 把回执里的 `passed` 当成待复核声明：核对冻结 336 规范、案例文件、数值源码范围哈希，并重算完成数/超时/p95。空回执、错源码、漏文件、只有状态的空壳、非法 EV/概率、以及多个案例指向同一结果文件都会被拒绝。完整结果必须能对上该案例的输入组成。

运行包从 **git HEAD 文件树 + 发行允许清单** 打包，不是扫描脏工作目录。`BUILD_INFO.json` 同时有计算文件清单（`source_manifest`）和发行完整清单（`package_manifest`，含 fixtures）。Git 忽略的 `.env` / `*.sqlite3` 不会因工作树干净而被带出。未授权不要把当前脚本生成的副本发给别人。PR #12 已合入 `main`（`17c6643`）。

干净运行副本不含用户 SQLite、`.analysis`、`.git` 或 `.local-native` 二进制；首次运行自建空数据库。

对照实验入口在主界面「对照实验」。固定移除若干张已知牌面不等于实际经过三/六轮。当前手牌 EV 不是下一轮下注优势。
