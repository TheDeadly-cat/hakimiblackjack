`scripts/split_benchmarks.py` 与 `scripts/verify_split_release.py` 仍是无 DAS 的 b1 交付，不能换签为 DAS 成绩。336 矩阵、318 项 unittest、旧 318 个 b1 冷请求是三份不同证据。

干净运行副本不含用户 SQLite、`.analysis`、`.git` 或 `.local-native` 二进制；首次运行自建空数据库。`BUILD_INFO.json` 在没有 git 时校验源文件摘要。
