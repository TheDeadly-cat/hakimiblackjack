# 分牌先补齐与21点自动跳过

常用设置的新牌靴采用“分牌后两手各补一张，再先第一手、后第二手行动”。未补齐之前不能停牌、补牌或加倍决策；继续输入点数即录入下一张应发牌。分A仍每手只补一张，分出的21仍按普通21结算。

原手、补牌后的手和分手达到21点时自动跳到下一手／下一位；全部玩家完成后转庄家。Backspace撤回最后一张后重新确定目标。原始事件不追加人为停牌，历史显式停牌事件仍可恢复。旧牌靴继续使用锁定顺序；新顺序通过新建常用设置牌靴启用，不改旧记录。

## 概率与EV口径

当前手牌按所有已知牌扣除后的剩余牌盒、未知庄家底牌及实际非BJ检查，有限不放回枚举下一张牌及后续动作。补牌EV包含后续按新牌选择的继续行动，不是补一张便强制停牌。推荐按最高预期净收益（EV）排序，未必是最高赢牌概率。多人仍按“其他玩家之后不再补牌”的显式条件分别计算。

新分牌引擎 `finite-two-initial-das-1` / 策略 `both-second-cards-visible-total-net-das-v1`：先积分第一、第二手的初始补牌，再按两手已见牌选择第一手行动；第二手之后使用全部新增信息。按实际抽牌先后进行条件概率更新，不偷看底牌、不独立卷积。第一手缓存只在第二手已知状态相同时复用。原顺序引擎及历史结果保留各自身份。

标题的下轮开局EV另用 `opening-finite-mc-v3`，按锁定分牌顺序模拟真实有限发牌。它仍估算事先确定的固定策略及95%抽样误差，不能与当前手牌的有限最优比较混为一谈。
