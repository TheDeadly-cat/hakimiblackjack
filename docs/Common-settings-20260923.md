# 默认与一键常用设置

新打开程序的设置已包含8副牌、S17（含软17）、同点值分牌、late晚投降、任意初始两张可加倍、非A分牌后可加倍，以及简便暗牌。无需选择研究模板或单独勾选暗牌选项；在小面板点击“新建牌盒”，再点“开始本轮”即可按顺序录牌。

“录牌设置”中增加“一键常用设置”，工作台模板菜单也可找到同一入口。它恢复整套表单设置，不写牌面、动作或结算。新牌盒使用新桌规；简便暗牌从下一轮生效。已有牌盒的锁定规则、录牌计划和事件保持原样，重开恢复也不会将未知规则猜成这套预设。

该本机预设沿用既有同点值DAS模型的其他设置：BJ赔付3:2、美式底牌、A或十点明牌时单独确认非BJ、完整新牌盒及初始零烧牌、最多两手顺序分牌、无再分牌、分A只补一张、分牌后不投降。首手完成后再给第二手补牌。规则来源注明本机用户预设，不能据此认定任何外部牌桌规则已经核对。

初始明牌录完后自动登记一张未知底牌；轮到庄家输入点数时只揭示原牌。Backspace仍撤回上一步，撤回底牌后可重录，撤回爆牌后回到对应玩家。庄家S17自动停牌、玩家爆牌自动切换与逐玩家自动计算继续保留。

新回归从空数据库启动，不借助模板按钮或修改勾选项，覆盖默认规则、简便暗牌、S17、J/Q同值分牌、晚投降可用、分后加倍、一键设置不修改当前牌局、旧规则及未知规则恢复。旧手动录牌测试显式选择其原始模式，继续验收手工暗牌与未知规则路径。
