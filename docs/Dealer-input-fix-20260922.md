# 庄家底牌键盘重复输入修复

在固定候选 5470375 上复现：按住数字键揭示底牌后，同一窗口内从按钮切换焦点至根窗口，原 FocusOut 处理会清空 RepeatGuard；按键尚未松开产生的重复 KeyPress 被再次执行，变成一张新的庄家补牌。

修复仅调整录牌键绑定的焦点边界。FocusOut 后等待焦点转移完成，同一录牌窗口内保留已按住的键；真正离开录牌窗口才清除失效状态。关闭窗口会取消待执行的焦点检查。没有按时间吞掉相同点数，松开再按仍可正常录入两张同点数牌。

`tests/test_dealer_key_repeat.py` 用真实 Tk 事件和临时数据库覆盖未松键内部转移焦点、主键盘与小键盘、A/a/1、第二次独立按键、离开录牌窗口和待处理回调关闭。Windows Tk 的小键盘测试使用真实数字虚拟键码，因该平台不能用 `event_generate(keysym='KP_1')` 合成键码。

改动不涉及概率公式、桌规、SQLite结构或既有历史记录。用户原练习记录保留；不自动删除历史上看似重复但无法确认实际来源的牌。
