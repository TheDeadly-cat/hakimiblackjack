# 资料保全与恢复清单

备份前正常关闭程序，等待已接收录牌、回执和必要结果保存完成。保存结果待核对时，先保留整份资料；核对前不能重试录入同一张牌。优先完整复制所选数据库所在的研究资料目录到一个新的备份目录，再在另一目录验证恢复；仅复制 `.db` 不能保全所有分析和输入证据。

同一个数据库的资料包括：

| 文件或目录 | 保全用途 |
|---|---|
| 数据库及仍存在的 SQLite 配套文件 | 已保存账本、会话和牌靴 |
| `*.analysis/`、`*.opening/`、`*.sidebets/` | 原时点判断、原始输入、结果及来源身份 |
| `*.deal_plans/`、`*.ui-preferences.json` | 冻结发牌计划和界面设置 |
| `*.sidebet-profile.json` | Pragmatic 边注设置 |
| `*.table-modes.json` | 两个模式分别保存的规则与开关 |
| `*.table-modes.json.history/` | 升级前完整原设置字节；不能当作普通缓存 |
| `*.bclc-sidebet-profile.json` | BCLC 独立赔付、A顺子细则及未确认状态 |
| `*.recording-failures/` | 未保存、未执行或提交结果不明的原始输入及核对标记；不能当作临时日志删除 |
| 实验设置、JSON/CSV输出、用户导出及原始材料 | 研究参数与可复核材料 |

模式设置损坏时保留原文件。健康数据库仍可恢复，其锁定规则不会因设置损坏而被替换。修复前不能用缺失字段补成“已确认”的桌规。恢复待核对录牌时，原输入继续暂停，核对标记必须与原文件摘要及已保存前缀一致；不会自动补录或重试。

本轮用临时合成数据库执行了完整文件夹复制及独立目录恢复，核对模式原文、升级历史、BCLC边注设置、失败原输入和账本。该验证没有读取日常数据库，也不代表已经替用户做过真实备份或磁盘清理。现有备份工具采用完整目录复制，新状态文件随目录一起保留；此清单补足新增资料分类。
