# 规则能力矩阵（V0.1.1）

本表只说明实际交付的记录与确定性记账能力。未实现概率、策略优化或识别，不把规则字段存在当作算法验收。

| 能力 | 状态 | 范围与证据 |
|---|---|---|
| 6/7/8 副，312/364/416 张标准牌 | 已验证 | 初始化、全靴扣尽、烧牌/暗牌容量、十点桶与具体十点牌联合约束 |
| 有限不放回牌靴、新轮/新靴 | 已验证 | 新轮累计；结束牌靴拒绝继续开轮；撤销后恢复正确上下文 |
| 庄家与 1～7 玩家，空座和参与者变化 | 已验证 | 未参与座位拒绝录牌；UI 可选择下一轮参与座位 |
| 原始13牌面、T未细分、未知花色 | 已验证 | T 在同点值规则可分牌；同牌面规则仍需细分；不伪造具体牌面 |
| 补牌/停牌/加倍/分牌记录 | 已验证 | 关闭手、重复加倍、未确认手、庄家玩家动作拒绝；分后加倍必须得到规则明确允许 |
| 分A/再分A与分牌21 | 已验证 | 原手与新手均标记分牌来源；分牌21不享受天然 BJ 赔付；配置允许时可再分A |
| 天然 BJ、3:2/6:5 赔付 | 已验证 | 按原始一单位净收益记账；未知赔付遇天然 BJ 拒绝结算 |
| early/late 投降 | 已验证（记录层） | 初始两张且未采取动作、不能分牌后投降；late 在庄家可能 BJ 时需否定检查或已确认非 BJ |
| 庄家 BJ 时追加注全部损失 | 已验证 | 需要明确声明 all_bets_lost；计入分牌与加倍总追加额 |
| 庄家 BJ 仅原注损失/其他追加注组合 | 未支持 | 存档允许已知候选值；实际触发结算时拒绝输出收益 |
| S17/H17 字段 | 部分验证 | 结算时检查已声明的庄家终局条件；没有自动执行庄家策略 |
| 暗牌/未知牌/烧牌/缺口分离 | 已验证 | 揭示具体目标不清除其他候选；中途加入/未知烧牌数量标记缺口 |
| 幂等/冲突/撤销/纠错 | 已验证 | 相同ID相同内容幂等；冲突拒绝；多次纠错合成且可撤销；后续操作矛盾会整体拒绝 |
| SQLite 多会话和异常退出恢复 | 已验证 | 会话内序号唯一、保存事务、导入回滚、真实子进程退出、v1备份迁移 |
| JSON/CSV 导出与导入、会话切换、备份 | 已验证 | 新 CSV event_json 保留全部身份；旧摘要 CSV 只读；导入不能覆盖已有历史 |
| 中文界面与历史时点查看 | 已验证（指定场景） | 7个Tk回调工作流；1360×900、1180×800自建场景截图核对；历史不使用后续信息 |
| 原牌面与分组数展示 | 已验证（账面统计） | 含尚未确认移除的未知牌，不能作为待发组成或概率 |
| 规则纠错分支 | 未支持 | 改规则采用新建牌靴；不能在原靴上静默换规则 |
| 每轮重置/未知牌靴模型 | 未支持 | 创建牌靴时拒绝；不套用有限不放回核算 |
| 概率、EV、整轮净收益分布 | 未支持 | V0.2 范围，当前不显示占位数值 |
| 离线识别、捕获、平台适配 | 未支持 | V0.3/V0.4或另行任务；无真实平台接入 |

未知规则保留未知。无已知记录缺口只表示账本状态，不代表该规则已得到外部核实。完整规则字段见数据字典与 RuleProfile，当前验证输出见 V0.1.1 复核报告。
