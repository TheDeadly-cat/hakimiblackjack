# 原生区域观察与相同输入调度：实现及实机结果

本次给实时预览增加原生区域变化、相对细节和尺寸提示。比较的是上次**完成识别**的输入；完全相同的输入不再次调用模型，也不增加支持票、刷新最近看见时间或延长稳定结果。新画面仍进入原检测器。没有重训、改变牌级阈值或宣称识牌率提高。

实机运行代码为 `91effb0dfc4c63e4ed58e7e268fb6446745ca8c6`。私有原录像、模型和逐帧记录仍在本地忽略目录，文档提交不倒填运行收据。

## 运行行为

- 录像来源在现有生产线程观察已接收的图像；WGC 在现有生命周期线程读取最新预览，推理线程对尚未观察的输入补查。没有新增采集器或观察线程。
- 每个标定区域计算原生像素摘要、灰度范围和边缘细节；小灰度缩图描述变化。细节历史最多 256 项／5 秒，帧缓存 64 项，证据条数受原配置限制，不逐帧留存全尺寸图片。
- `detail_decreased` 仅表示比最近画面的边缘细节少，`little_detail` 表示灰度变化少。它们不是可读概率，也不改变模型接受门槛。RGB 原生 1850×520 输入要求保持；旧模型没有据此新增通用尺寸下限。
- 完全相同的图像复用已有显示及其过期时间。抽样帧签名相同、但原生像素不同，仍识别；未处理的新画面不会被“与上一源帧相同”错误跳过。
- 当前检测器仍使用整个捕获图，区域外候选仍可能送到 `unassigned` 核对。因此相等性也包含全图摘要，尚未实现只检测变化区域。只改动区域外像素也会触发识别。
- 黑屏或处理输入之间超过现有身份时限 650 ms 时撤回预览身份，清除已完成输入摘要；恢复相同画面会重新识别。会话内 ID 序号不回收。断档不会用历史牌级补成新观察。
- 来源代次改变时拒绝旧结果；较旧的推理补查不会借用未来的源帧细节历史，也不会覆盖最新质量提示。

观察默认开启；CLI 的 `--disable-region-observation` 保留旧调度，便于对照。模型选择和重新播放保留当前设置。

## 实际 WGC 检查
