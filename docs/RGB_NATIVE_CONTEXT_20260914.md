# RGB 原生分块输入：固定方案与实际结果

原生分块减少了漏框，真实 1 倍速回放的可核实正确稳定事件从 9/31 提高到 14/31，搭配已冻结 CNN 为 15/31。但错误、上下角重复和身份碎片仍存在，计算成本也增加；分块保留为显式实验选项，秒级与仅正向上角的目标尚未通过。

现有检测器训练时输入 320×320 局部图，实时推理却输入整张 1850×520 牌区。骨干中含 6 个全局 Squeeze-Excitation 模块，局部内容相同时，周围画面仍可能改变输出。训练源 201 个正向目标中，整图已匹配 200 个、按标签取局部图匹配 201 个；不是完全未学会训练素材。

对既有 16:33 录像 31 个新可读事件，各取可读上界之后的一个可判位置，整图在这些单独时刻匹配到 6 个，按已知目标位置取原生 320×320 图后匹配到 19 个，增加 13、无减少。此处裁区使用了参考标签，仅用于定位输入上下文问题，不是可部署的识别方法或新盲测成绩。原 92 秒事件计数、31 个分母、参考与模型均不改写。

固定实现方案：320×320 原生网格，步长 160，最后一块靠齐边缘，不改变整幅图缩放。相邻块按中心中线分配输出区域，内部目标中心至少有 80 像素上下文，对应训练采样器的 70 像素最低边距。分块位置仅由图像尺寸决定，不读取标签、模型牌级或未来帧。1850×520 共 33 块，每批最多 8 块。块内输出映射回原图，再以原 IoU 0.3 去重，最多返回原有 96 个候选，同时记录截断数；重叠块不产生多次跨帧支持。

只改变推理上下文；RGB 权重、检测阈值 0.35、HOG 权重及门槛保持不变。原整图策略继续保留，分块策略使用独立身份摘要，并作为显式实验选项。既有小窗口仍受原 1850×520 输入范围约束；裁切不产生原画面没有的笔画细节。

先用现有原图做整图／网格对照，再执行真实 1 倍速窗口。报告完整目标分母、误收、未匹配、候选截断与新增计算成本，不能把标签定位的 19 个直接当作网格成果。后续数据分别保存，旧记录不覆盖。

期限计数保留全部 31 个事件，条件 P95 只涵盖出现相应结果的事件。首次可读与位置仍有区间和未判部分，计数是可判锚点上的证据，不能解释为精确全帧召回或完整身份正确性。三轮未发现可判锚点的跨目标 ID 合并，但 ID 碎片增加，额外输出及归属尚未完整核准。

实际截图也显示同一红 8 的上、下角同时输出，以及桌布位置的额外候选；“仅正向上角”仍不成立。分块改善输入上下文与漏框，不等于整条识牌可靠。此诊断没有单独消融全局汇聚层，不能将所有差异归因于某一层。
