# 独立小 CNN 分类对照：方案与实际结果

一次固定训练和旧／新对照已执行。CNN 在人工裁片上提高正确数并减少错认，但自动框上错认增加，真实回放的正确稳定事件从 9/31 降为 7/31。此候选不替代旧模型，不改变秒级目标未达标的结论。

原 RGB 检测对照及 HOG 权重继续冻结，不改写先前结果。正确人工上角直接分类仍有大量拒识，因此按原任务的先后顺序，单独比较一个小 CNN。此实验先验证分类能否改善，不默认替代现有模型，也不宣称秒级目标已达到。

输入保持原人工墨迹掩膜与 `mask_to_patch` 的 32×32 归一化；不更换检测器、不新增 52 类整牌或花色、不使用倒置下角。输出为 13 个原始牌级和 junk，分数是未经校准的 softmax，未知和拒识继续保留。

固定训练来源为 20:03 录像的 270 个已审裁片，与旧 HOG 的拟合输入相同，包含 165 个牌级和 105 个 junk。另源 20:21 的 189 个验证裁片、20:42／21:12 的 164 个旧留出裁片均不参与拟合；这些材料已有开发历史，不包装成新盲测。已有 16:33 录像整源继续不进入训练或阈值选择。复用现有来源、物理牌、二值内容分组与防泄漏检查，不重新划分相邻帧，不改变原人审记录。

一次固定实验：随机初始化 16／24／32 通道的三层小卷积网络，4×4 空间特征接 64 单元分类头，dropout 0.15；不下载预训练权重。训练增强仅沿用 0、±15、±30 度，按类别均衡采样，batch 64，AdamW 学习率 0.001、weight decay 0.001、label smoothing 0.02，种子 914，固定 1500 步。只保存最后一步，不按验证／留出结果选择 checkpoint。推理不旋转或角度搜索；接受门槛预先固定为最高分 ≥0.90 且前两类差值 ≥0.20，junk 始终拒识。

计划在任何 CNN 拟合前保存队列、训练内容、旧权重与检测器摘要。输出目录不覆盖旧实验，权重为不含 pickle 的 NPZ。训练结束先冻结新权重，再分别运行旧／新分类器对照，报告正确、错误、拒识、junk 误收及完整分母。裁片层结果不代替检测、物理身份或全视频验收；若分类有收益，再用冻结检测器和现有实时入口验证整条流程，所有失败保留。

| 自动框 | 方案 | 正确 | 错认 | 拒识 | 未匹配目标 | 额外接受输出，真伪未全判 |

## 真实 1 倍速回放

同一代码、同一 16:33 录像的前 92 秒、8 FPS、原生 1850×520 输入和现有 36 个参考事件，两轮串行运行实际 Tk 窗口。两次均完整结束、退出 0、原生显示，无元数据溢出；实际窗口截图已查看。两轮界面鼠标／键盘事件均为 0，没有正式确认或账本写入。此处使用已有源图参考及其勘误，不是新盲测，也不是 CNN 的 WGC 识牌输入验收；WGC 仅用于截取本轮自有预览窗口。

| 31 个新可读事件及计时 | RGB＋HOG | RGB＋CNN |
| --- | ---: | ---: |
| 实际处理帧 | 676 | 680 |
| 可核实正确稳定事件 | 9/31 | 7/31 |
| 1 秒内正确稳定，起点区间计数 | 3–5/31 | 2–3/31 |
| 2 秒内正确稳定，起点区间计数 | 6–7/31 | 4/31 |
| 未匹配候选事件 | 18 | 18 |
| 仅未知候选事件 | 2 | 6 |
| 曾错误候选／错误稳定的可判事件 | 2/1 | 0/0 |
| 首次正确稳定条件 P95 | 26.234–26.543 秒 | 30.841–31.116 秒 |
| 分类阶段 P95 | 23.23 ms | 3.62 ms |
| 取帧→候选显示 P95 | 140.12 ms | 125.46 ms |

0.5 秒内正确稳定的已验证下界两者均为 0/31。期限计数保留全部 31 个事件；条件 P95 只涵盖出现相应结果的事件，位置未判区域可能遗漏更早输出，不把它称为精确首次延迟。错误数仅涵盖可判锚点，不代表全输出零错误；完整物理身份和归属仍未通过。CNN 减少了部分错误接受，同时多拒绝了可用牌面，稳定命中没有提升。两者共同的 18 个未匹配事件需要继续检查检测和输入，不能靠换分类器恢复没有送入的角标。

另用同一份权重比较 CPU／CUDA：154 个既有掩膜的原始类别、接受／拒识与最终牌级全部一致。包含掩膜归一化和传输的整次分类调用，8／16／32 裁片批次的 P95 分别为 CPU 1.12／1.53／2.34 ms，CUDA 0.98／1.21／1.33 ms；每种规模预热 5 次后测 30 次，不含检测、录像解码或 UI。

## 使用与证据

主程序明确选择 CNN 模型目录时可加载它，缺少 PyTorch 则报错并保留当前核对。没有自动寻找或升级到最新权重。独立实时入口增加可选 `--cnn-model`，与 `--detector` 配合；下拉框可选择「RGB + CNN」。仅提供 CNN 路径不会自动选中它，需要显式指定 `--initial-method rgb-cnn` 或在窗口中选择。两个分类变体共享常驻 RGB 检测器，重启仍先停止旧处理。

本机显式实验命令：

```powershell
& '.\.local-evidence\rgb-corner-prototype\venv\Scripts\python.exe' scripts/realtime_preview.py `
  --video 'C:\Users\Administrator\Videos\NVIDIA\Desktop\Desktop 2026.09.13 - 16.33.19.08.mp4' `
  --style '.local-evidence/continuous-review-20260913-21-12/runtime-inputs/style.json' `
  --model '.local-evidence/review-completion-20260913-003511/upright-training-run/model' `
  --detector '.local-evidence/rgb-corner-prototype/training-2-background' `
  --cnn-model '.local-evidence/rank-cnn-experiment-20260914/run-1/model' `
  --initial-method rgb-cnn --device cuda --fps 8 --last-frame 11040 `
  --evidence-limit 4096 --geometry 2000x1120 --close-on-finish
```

私有权重、计划和结果位于 `.local-evidence/rank-cnn-experiment-20260914/`，分别为 `run-1`、`paired-static-1`、`realtime-pair-1` 与 `cpu-cuda-classifier.json`。两轮实际回放原 `run.json` SHA256 为 `93ba3208c425b34c6854a2a4c59100a3d893e9b85266e0ab1f73cd3be8b12963`、`f4801cdf5c756621e13e777b6c559e67aaaa16b49e9fd507315efa5380e2420b`。训练及运行记录分别绑定实际代码，不重签旧实验。

新增 3 项本地 PyTorch 合成契约，覆盖空墨迹／junk／不确定／非法方向拒识、批内结果互不改写、模型摘要和覆盖保护，以及明确样式加载。与现有模型适配、实时预览、冻结核对合计 30 项通过；组合末尾仍有已记录的旧 Tk ThemeChanged 清理警告。CI 未安装 PyTorch 时跳过这 3 项，不以普通 CI 成功替代本机 CNN 验证；实际训练、静态原图、92 秒窗口与设备对照证据单列。
