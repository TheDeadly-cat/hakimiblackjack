# V0.2a 实现契约与验收起点

基线：337ce083cdcc598adcda9639c73d832ec9b1e232。依据用户《开发大纲调整版 r1》，本轮交付必要修复和实际分析闭环，未完成项目逐项登记，不以本文件替代交付。

冻结首个模板：6/7/8副、完整新靴、零烧牌、有限不放回、单参与玩家且未分牌、S17、3:2、美式底牌、A/十点明牌进入决策前明确检查非BJ、初始两张可加倍、晚投降或不投降。模板是自建研究规则，由用户主动选择，未知字段不得套用。

计数 C 包含一个未知底牌和物理待发牌。非BJ检查决定底牌允许集合 H。对下一张玩家抽牌 r：

`P(r | 已知信息) = C[r] * (sum(C[h], h in H) - 1[r in H]) / sum(C[h], h in H) / (sum(C)-1)`。

玩家抽到 r 后只从 C 扣减 r，底牌继续按新计数条件化。停牌结算先对隐藏底牌求条件平均；补牌后的每个可见信息节点在补/停间比较条件期望。严禁先按实际隐藏牌各自优化再平均。加倍只补一张，收益按 -2/0/+2 计；普通手按 -1/0/+1，天然BJ按0/+1.5，晚投降按-0.5。

生产路径为有限不放回枚举与浮点动态规划，不用蒙特卡洛代替真实精确路径。独立参考路径将枚举小牌靴的物理排列并以 Fraction 汇总相同可见前缀，独立实现庄家规则及支付。预定误差为绝对1e-10；模拟验证独立有种子、样本量和误差口径。

输入身份覆盖事件前缀摘要、规则全部内容、可见计数、正常未知牌/检查、目标与合法动作、引擎/策略版本。结果区分可用、不适用、未支持、待核对、计算中、取消、超时和过期；缺少合法分牌的EV时只能部分比较。

预算：典型请求p95目标2秒，硬预算5秒含明确超时处理。实测后报告p50/p95/最大与内存，不预先声明达标。旧事件schema 2保留；结果使用原子、不可覆盖的版本化JSON旁路，结果存储失败不回滚已提交的事件。

外部阅读仅用于核对问题定义：研究者对[牌靴组成相关策略](https://possiblywrong.wordpress.com/2016/11/02/distribution-and-variance-in-blackjack-part-2/)的讨论；本项目不并入第三方GPL代码，独立枚举为本轮主要验算证据。
