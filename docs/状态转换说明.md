# 牌靴与牌局状态转换说明（V0.1）

## 1. 牌靴（Shoe）生命周期

```text
[无牌靴]
   │ SHOE_CREATED（选 6/7/8，锁定 RuleProfile 快照）
   ▼
[进行中的牌靴] ──SHOE_ENDED──▶ [已结束牌靴]（只读保留）
   │ 多轮 ROUND_STARTED/ROUND_ENDED 循环，牌靴组成连续累计，不随轮次重置
   ▼
（再点 SHOE_CREATED = 全新一靴，独立 ShoeSegment，绝不与上一靴混算）
```

## 2. 轮次（Round）阶段机（`core/table.py`）

```text
未开轮 ──ROUND_STARTED──▶ 发牌中
发牌中 ──首个 PLAYER_ACTION──▶ 进行中        （也可在 ROUND_ENDED 时自动进入）
发牌中/进行中 ──ROUND_ENDED(settle=true)，双方终局完整且结算条件满足──▶ 已结算
发牌中/进行中 ──ROUND_ENDED(settle=false)，填写原因──▶ 已结束未结算
已结算/已结束未结算 ──ROUND_STARTED──▶ 发牌中（下一轮，沿用同一牌靴）
```

“结束并结算”在任意玩家/庄家牌不完整、加倍牌待补、赔付未知或追加注规则未支持时拒绝写入。
可以另选“结束本轮（未结算）”继续记录；未知牌与缺口继续保留。旧版结束事件没有 settle 字段时按完整条件尝试结算，失败则保留未结算，不伪造收益。

## 3. 手牌（Hand）状态

```text
新建手牌（0 张）
  │ 两张初始牌
  ▼
待操作 ──补牌──▶ 待操作（可继续，直到爆牌/停牌）
       ──停牌──▶ 已关闭(stood)
       ──加倍──▶ 待补唯一一张 ──补牌──▶ 已关闭(stood，注额×2)
       ──分牌──▶ 原手留 1 张 + 新子手(parent_id 指向原手)
       ──投降──▶ 已关闭(surrendered，按原始注 -0.5)
任一手牌点数 >21 ──▶ 已关闭(bust)
分 A 手牌按规则补满一张即自动停牌；若再次形成 A/A 且允许再分A，保留分牌机会
```

## 4. 记录完整性三档（`core/shoe.py`）

| 状态 | 触发条件 | V0.1 行为 |
|---|---|---|
| 可分析（内部历史状态名） | 无已知缺口、无待核对候选（庄家暗牌属正常隐藏） | UI 显示“记录无已知缺口（未运行分析）”，不表示存在分析引擎 |
| 待核对 | 存在候选/未识别牌（pending_candidates>0） | 记录继续，明确标注，不把候选当确定牌面 |
| 信息不完整 | OBSERVATION_GAP：断流/漏牌/数量未知移除 | 物理剩余不可知，牌靴级精确分析暂停（V0.2 生效） |

## 5. 撤销与纠错的重放语义

- 所有事件只追加；UNDO/CORRECTION 也是事件，不删除任何历史；
- 重放时：被 UNDO 指向的事件跳过；CORRECTION 的 `payload_fix` 覆盖目标字段后执行；
- 多次纠错按顺序合成，撤销最近一次纠错能恢复此前版本；纠错只允许牌面、花色、烧牌、缺口、检查状态字段，不允许改写事件身份与规则快照；
- 每次追加先完整重放验证，后续分牌等与历史纠错冲突时整体拒绝；失败不写入数据库；
- 结束牌靴后禁止继续录牌/开轮，撤销创建或结束事件后上下文由重放恢复；
- 撤销只允许逆序撤销"最后一个有效事件"（界面按钮语义），防止悬挂引用；
- 同一物理牌 track_id 在同一牌靴内只扣一次，撤销后允许重新入账；
- 验收等价性：`误记 + CORRECTION` 的重放结果，必须等于"一开始就记对"的新账本
  （`tests/test_ledger.py::test_correction_equals_replay_from_correct_start`）。

## 6. 信息隔离（大纲 3.3）

1. 庄家暗牌：记录"存在且未揭示"，未揭示前不认定牌面、不参与结算；
2. 已知数量烧牌：只记数量与未知，不猜牌面；
3. 观察缺口：不凭概率补牌，暂停精确分析；
4. 防泄漏测试：暗牌揭示前，无论未来翻成 K 还是 Q，"当时可见信息"的组成完全一致
   （`test_hidden_future_invisible`）。
5. `replay(through_seq=N)` 只使用截至 N 的事件前缀，后来的纠错与揭示不会改变该历史视图。
