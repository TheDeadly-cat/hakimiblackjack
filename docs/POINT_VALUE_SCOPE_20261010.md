# 点值版运行范围与验证

本轮从 PR #38 的 `40e239df642a6a45a4d4f278644586097c41831a` 收缩正常运行范围：A–9、T录牌与主注自动分析继续使用；Perfect Pairs和21+3不自动预测、不观察生成新实时快照。保险和庄家BJ指标仍依其条件与规则显示。当前候选未替换独立日常版，仍为Draft。

## 独立能力限制

`BlackjackLabApp` 的 `auto_analysis=True` 保持原默认值。新的 `sidebet_research=False` 与主注开关独立；正常入口和BCLC候选启动器均使用此限制。旧边注配置即使 `enabled=true` 也只能读取，不能解除能力限制；启动、模式切换、录牌、关闭与重启不重写配置原文。

点值版保留历史读取与原配置查看，不提供边注历史复算或配置覆盖。研究组件、三态编辑器、既有精确牌面和花色字段没有删除。可选研究入口需要明确使用：

```text
python -m blackjack_lab.main --db <owned-research-db> --sidebet-research
```

研究入口可关闭实时边注。关闭后不派发新预测或观察，已经接受的计算保留原请求，已完成未保存结果仍走原保全、显式重试及退出确认；不把停用当作丢弃结果的授权。研究能力也不把未知T细分为四种牌面，不补未知花色。

## 空闲读取修复

边注先比较上下文、模式选择、座位、规则摘要、实际启用状态及录牌状态等轻量信息，再进入完整读取帧。没有变化时不捕获历史前缀。模式切换和真正的新分析仍经原完整读取/验证路径；账本、SQLite历史基线、恢复验证与主注数学引擎没有削减。

停用且工作队列、活动任务和完成队列都空时，不再安排边注60毫秒轮询。显式保存重试临时启动轮询，完成后停止。后台工作者在同一个锁内先发布完成消息再标记空闲，避免停止空闲轮询后错过完成消息。

修改前在真实Tk、10,001条冻结合成历史上，关闭/开启边注各100次不变刷新均触发100次完整前缀捕获，分别约44.87/45.08秒。修改后的同一历史上，正常入口强制停用、可选研究关闭/开启等四种状态，各100次刷新加轮询均为0次捕获，约6.3–7.5毫秒；停用状态没有安排轮询。此处计时是方法诊断，未把这些数值当成完整录牌性能或CPU使用率。

固定源码 `affd494` 在完整录牌测量结束后再次运行相同空闲诊断：四种状态各100次刷新加轮询仍为0次捕获，约6.2–6.6毫秒；停用状态没有轮询，主注保持开启。前一工作树诊断的原输出保留，未重新签为固定源码结果。
