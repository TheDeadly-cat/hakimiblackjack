# 实时窗口/显示器捕获（Windows Graphics Capture 的 Rust 绑定，MIT）。
# 轮子为 cp39-abi3-win_amd64，因此在 Python 3.14 上可直接安装。
# 本机实测：显示器捕获 2560x1440 BGRA，4.04 秒 184 帧；首帧 219ms。
# 实测限制（不是缺陷，必须按此设计）：
#   1. 变化驱动——画面不动就没有新帧，静止窗口只给一帧。
#   2. 阻塞式 start() 在没有新帧时不返回，只能用 start_free_threaded()。
#   3. 最小显示器序号是 1，传 0 会被后端拒绝。
# 未安装时：实时捕获不可用并明确提示；录像回放与本地图识牌不受影响。
